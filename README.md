# produktif-glow

Landing page link-in-bio Produktif Glow: https://produktif-glow.vercel.app

## Cara update produk
Edit array `POSTS` di `index.html` (postingan terbaru di paling atas):
- `kategori`: "skincare" atau "meja"
- `pin`: nomor label di foto postingan
- `link`: link Shopee (s.shopee.co.id/...)

Setiap commit ke branch `main` otomatis tayang lewat Vercel.
